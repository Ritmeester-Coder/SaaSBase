# SaaSBase

A reusable SaaS application foundation built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, Supabase, and Resend.

## Current Foundation

- Next.js + TypeScript
- Tailwind CSS
- shadcn/ui + Base UI
- Light / dark theme
- Responsive application shell
- Sidebar navigation
- Application header
- Supabase authentication
- Email confirmation
- Resend SMTP
- User profiles
- Multi-tenant companies
- Company memberships
- Owner / Admin / Member roles
- Row Level Security
- Company onboarding
- Protected application routes
- Login / logout
- Server-side Supabase access

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Base UI
- Lucide
- Supabase
- Resend

## Getting Started

Install dependencies:

```bash
npm install
```
